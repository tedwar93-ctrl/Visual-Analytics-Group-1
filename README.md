# Visual Analytics Group 1

## Project Description
[The purpose of our app is to provide a dashboard for the CMO of a grocery store to make enhanced data-driven decisions on promotions. Instead of looking only at the basic sales data, we aim to emphasize comparing pre-, during, and post-promotional data to inform the CMO if a promotion truly outperforms normal sales, while also showcasing any steep post-promotional declines or increases in sales.]
